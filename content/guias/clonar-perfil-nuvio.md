O **Clone Profile** do NuvioSync copia o conteúdo de um perfil Nuvio para outro — na mesma conta ou numa nova. O caso de uso mais comum é configurar o perfil de um familiar: configuras o teu setup uma vez e clonas para o perfil deles em segundos.

**O que podes clonar:**
- Biblioteca (filmes e séries)
- Addons instalados
- Colecções
- Histórico de visualizações
- Continue Watching

Podes escolher quais secções copiar — não tens de clonar tudo.

---

## Antes de começar

> ⚠️ A clonagem **substitui** as secções seleccionadas no perfil de destino. Se o perfil de destino já tem dados que queres guardar, faz um backup primeiro — o NuvioSync oferece esta opção durante o processo.

---

## Passo a Passo

### Passo 1 — Ligar o Nuvio

Abre [nuviosync.com](https://nuviosync.com) e em **Clone Profile**, faz login com a tua conta Nuvio.

### Passo 2 — Seleccionar o perfil de origem

Escolhe o perfil que queres clonar (o teu setup principal, por exemplo).

### Passo 3 — Seleccionar o perfil de destino

Podes escolher:
- **Um perfil existente** — os dados seleccionados são substituídos
- **"New profile"** — o NuvioSync cria um perfil novo na tua conta e clona para lá directamente, sem precisares de ir à app Nuvio

### Passo 4 — Backup do perfil de destino (recomendado)

Se o perfil de destino já tem dados, o NuvioSync oferece a opção de fazer download de um ficheiro JSON de backup antes de prosseguir. Guarda-o — serve de ponto de restauro.

### Passo 5 — Escolher o que copiar e confirmar

Selecciona as secções a clonar e confirma. O NuvioSync escreve os dados e mostra o resultado.

---

## Notas Importantes

- O Clone Profile funciona **dentro da mesma conta Nuvio** — não copia entre contas diferentes.
- Os addons são clonados como URLs. Se algum addon precisar de API Keys específicas (como o AIOStreams com Debrid), o familiar terá de as inserir nas definições do addon depois da clonagem.
- Se quiseres clonar para a conta de outra pessoa (conta diferente), usa a opção de **Backup & Restore** do NuvioSync: exportas o perfil como JSON e o familiar importa-o na conta dele.
