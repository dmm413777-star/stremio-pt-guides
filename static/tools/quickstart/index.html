📺 QuickStart PT

Instala o pack de addons portugueses na tua conta Stremio em menos de 2 minutos.

1 Login Stremio ✓

🔒 As credenciais são usadas apenas para comunicar com a API oficial do Stremio (api.strem.io) e não são guardadas em nenhum sítio.

2 Selecionar Pack

3 Instalação

Esta ferramenta usa a API oficial do Stremio. Os addons são instalados na tua conta como se usasses o Stremio normalmente.
Para remover um addon, abre o Stremio → Addons → desinstala manualmente.
